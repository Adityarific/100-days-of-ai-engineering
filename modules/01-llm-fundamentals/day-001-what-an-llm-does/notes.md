# Day 1: What an LLM Does

## 1. What is an LLM?

A Large Language Model (LLM) is a neural network trained on large amounts of text to learn patterns in language. It can generate text, answer questions, summarize information, translate languages, and help with coding.

## 2. How does an LLM produce an answer?

When I send a prompt, the model converts the text into tokens and processes them using its learned parameters and the current context. It then predicts a probability distribution over possible next tokens, selects a token according to its decoding settings, and repeats this process until it generates an answer or reaches a stopping condition.

## 3. Why can an LLM sound confident while being wrong?

An LLM is trained to generate likely continuations of text, not to guarantee that every statement is factually correct. It can produce fluent, convincing answers that contain false information because plausible language and factual accuracy are not the same thing.

## 4. What is a token?

A token is a unit of text processed by a language model. Depending on the tokenizer, a token may represent a word, part of a word, punctuation, or another text unit.

## 5. What is temperature?

Temperature changes how the model's output probabilities are used during sampling.

- Temperature 1: uses the model's normal sampling distribution.
- Temperature 0: requests the most deterministic decoding behavior supported by the API.

Temperature 0 does not guarantee identical answers across every model, backend, or request.

## 6. Why can the same prompt produce different answers?

A prompt does not necessarily determine one fixed output. Sampling, model configuration, backend behavior, and other factors can produce different continuations even when the input text is unchanged.

## 7. What are tokens and latency measurements?

- Input tokens: tokens sent to the model.
- Output tokens: tokens generated by the model.
- Latency: time taken for a request to complete.
- Cost: provider-specific charge based on the model's pricing and billable usage.

An LLM generates text by repeatedly predicting and selecting tokens. Its fluency can make an incorrect answer sound reliable, so important claims should be verified against trustworthy sources.
